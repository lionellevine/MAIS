# Audit records

The research agendas are AI-written mathematics, so their provenance should be inspectable rather than ceremonial. This directory collects dated audit records for the editions in the repository.

The first public round is [July 2026](2026-07/). It includes the pre-repair audits, scoped checks of the findings most capable of changing mathematical content, a released-edition repair log, and the final integration-gate result.

An audit is evidence, not a warranty. The agendas have not undergone conventional human peer review, and no human has verified every line.
