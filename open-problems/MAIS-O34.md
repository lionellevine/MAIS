# Exact identified set for two-variable causal models

*Open problem MAIS-O34 · posed in [MAIS-A2](../agendas/A2/) as [Problem 5.2](../agendas/A2/MAIS-A2.tex#L376) · Status: open.*

*Tags: interpretability · world-model discovery · eliciting latent knowledge · black-box evaluation · algebraic geometry · computational. Difficulty: ★.*

*Authored by: Claude 5 Fable directed by Lionel Levine · Audited by: GPT 5.6 Sol.*

The smallest environment supporting a causal question has two binary variables and one arrow: does $X$ cause $Y$ or $Y$ cause $X$? An agent is paid a known function of its action and both variables, observes nothing, and acts near-optimally under every mixture of local interventions. Which models of the environment are consistent with its behavior? Here the question is three unknown parameters, one binary structural choice, and sixteen explicit quadratic polynomials — small enough to answer exactly, and the answer is not known.

The **two-variable family** $\mathcal{M}_2(\lambda)$: chance variables $\mathbf{C}=\lbrace X,Y\rbrace $, observation set $\mathbf{O}=\emptyset$, utility parents $\mathbf{Z}=\lbrace X,Y\rbrace $, and a fixed utility $u\colon\lbrace 0,1\rbrace ^3\to[0,1]$ whose gap $g(x,y)=u(1,x,y)-u(0,x,y)$ satisfies $|g|\ge\lambda$, takes both signs, and is sensitive to each variable: flipping either argument changes $g$ by at least $\lambda$ at some value of the other. The agent chooses a single binary action $d$, which influences nothing but its score $u(d,x,y)$. A model is a pair $M=(G,\theta)$: graph $G_\to$ ($X\to Y$; parameter triple $\theta=(a,b_0,b_1)$ with $a=P(X{=}1)$, $b_x=P(Y{=}1\mid X{=}x)$) or $G_\leftarrow$ ($Y\to X$; $\theta=(b,a_0,a_1)$ with $b=P(Y{=}1)$, $a_y=P(X{=}1\mid Y{=}y)$), all parameters in $[\lambda,1-\lambda]$ and edge strength $|b_0-b_1|\ge\lambda$ (resp. $|a_0-a_1|\ge\lambda$).

There are sixteen intervention profiles: each variable's value is left alone, fixed to $0$, fixed to $1$, or flipped to its negation — four options per variable — with the chosen map applied after the variable's mechanism fires, and any downstream mechanism reading the post-intervention value. A mixture $\sigma$ is a probability distribution over the sixteen profiles, one of which is drawn and applied. The behavioral transform is the vector $\bigl(\Delta_M(\sigma)\bigr)_{\sigma}\in\mathbb{R}^{16}$ with $\Delta_M(\sigma)=\sum_{x,y}P_M(x,y;\sigma)\ g(x,y)$, the expected advantage of playing $1$ over $0$; since $\Delta_M$ is linear in $\sigma$, its sixteen profile values determine it on all mixtures, and an optimal agent plays $1$ under mixture $\sigma$ precisely when $\Delta_M(\sigma)>0$. A policy family assigns to each mixture $\sigma$ an action probability $\pi_\sigma\in[0,1]$; it is regret-$\delta$ for $M$ if under every mixture its expected utility comes within $\delta$ of the optimum in $M$. The identified set $I_\delta(M)$ consists of the models $M'=(G',\theta')$ for which a single policy family is regret-$\delta$ for $M$ and $M'$ simultaneously — the models that no amount of behavior can rule out — and the error $e(M;G',\theta')$ is $1$ for a wrong graph ($G'\ne G$), else the largest difference of corresponding parameters.

**Problem ([MAIS-A2, Problem 5.2](../agendas/A2/MAIS-A2.tex#L376)).** For the family $\mathcal{M}_2(\lambda)$, write $r_M(\delta):=\sup_{M'\in I_\delta(M)}e(M;G',\theta')$ for the local radius of the identified set. (a) Determine, as an explicit semialgebraic condition on $(u,\theta)$, when the global fiber $\lbrace M':\Delta_{M'}=\Delta_M\rbrace $ is the singleton $\lbrace M\rbrace $; in particular decide whether margin $\lambda>0$ alone suffices. (b) On the locus where the inverse is locally Lipschitz and the graph is locally fixed, compute the first-order constant in $r_M(\delta)=c(u,\theta)\delta+o(\delta)$. On the complementary locus, classify the alternatives: a positive limiting radius, graph ambiguity, or a fractional-power modulus. Use this classification to determine the largest regret below which the edge direction is certain throughout the class.

Part (a) is a concrete real-algebra problem: quantifier elimination will decide any single instance, and the problem asks for the human-readable answer. Part (b) is a small but genuine piece of the geometry that the general regret-floor problem asks for. The agenda sizes it for a first paper. This family is the smallest instance of the setting in which Richens and Everitt [[RE24]](https://arxiv.org/abs/2402.10877) proved that near-optimal behavior under local interventions determines the causal model for almost every parameter choice; part (a) asks for the exact locus in the smallest case. For the general framework this family instantiates, see [MAIS-A2](../agendas/A2/).
