# Stochastic complexities of reduced rank regression in Bayesian estimation

*Summary [AW05] · M. Aoyagi and S. Watanabe, Neural Networks 18 (2005), no. 7, 924–933.*

*Tags: interpretability · generalization · singular learning theory · developmental interpretability · algebraic geometry · statistics.*

*Summarized by: Claude Fable 5 directed by Lionel Levine.*

**TL;DR.** The paper computes the exact learning coefficient $\lambda$ and multiplicity $m$ of reduced-rank regression, equivalently a network with one linear hidden layer and two weight matrices. The answer depends on the input, output, and hidden dimensions and the rank of the true map. It is an early exact solution for a genuinely singular model: the coefficient can be smaller than half the parameter count, and one parity class produces a $\log\log n$ term in the Bayes free energy.

## Setup and hypotheses

The model is $y = BAx + \text{Gaussian noise}$ with input $x \in \mathbb{R}^N$, output $y \in \mathbb{R}^M$, and parameter $w = (A, B)$, $A \in \mathbb{R}^{H \times N}$, $B \in \mathbb{R}^{M \times H}$, so $d = H(N+M)$. The map $x \mapsto BAx$ is linear, but the parametrization is not: for $H < \min(M, N)$ the representable maps form the singular variety of matrices of rank at most $H$. The truth is realizable, $q(y \mid x) = p(y \mid x, w_0)$, with $r = \operatorname{rank}(B_0 A_0)$. In Watanabe's framework the Bayes free energy expands as $\lambda \log n - (m-1)\log\log n + O(1)$, where $\lambda$ and $m$ are the threshold and pole order of the zeta function $\zeta(z) = \int K(w)^z\,\varphi(w)\,dw$ of the Kullback–Leibler divergence $K$ to the truth; the prior $\varphi$ is smooth and bounded above and below by positive constants near the optimal set. The task is to compute $(\lambda, m)$.

## Main results

With $r$ the rank of the truth, the pair $(\lambda, m)$ is (as restated in [MAIS-A6, Theorem 3.1](../agendas/A6/MAIS-A6.tex#L184)):

1. If $M + r \le N + H$, $N + r \le M + H$, and $H + r \le M + N$: $\lambda = \bigl(2(H+r)(M+N) - (M-N)^2 - (H+r)^2\bigr)/8$ with $m = 1$ when $M+N+H+r$ is even; add $1/8$ and take $m = 2$ when it is odd.
2. If $N + H < M + r$: $\lambda = (HN - Hr + Mr)/2$, $m = 1$.
3. If $M + H < N + r$: $\lambda = (HM - Hr + Nr)/2$, $m = 1$.
4. If $M + N < H + r$: $\lambda = MN/2$, $m = 1$.

Three readings. The coefficient depends on the truth only through the integer $r$ — all truths of the same rank are equally singular — which is why a closed form in a few integers exists at all. The odd-parity case has $m = 2$, so the free energy carries a $\log\log n$ correction: the formula is a genuine rational count from a resolution of singularities, not a dimension count. And the boundary case $r = H$ recovers exactly half the codimension of the optimal set — the Laplace-approximation answer — while the interior cases are strictly smaller: the excess degeneracy is precisely what parameter counting misses.

## Proof method

Direct resolution of the singularity of $K(w)$, which near the optimal set is comparable to $\|BA - B_0 A_0\|^2$. A recursive sequence of blow-ups, inductive in the matrix dimensions, brings $K$ to normal crossings; the largest pole of the zeta function is then read off and minimized over the resolution charts, yielding the case analysis above. The recursion is the reusable part: Aoyagi later ran the same scheme for linear networks of any depth (Neural Networks, 2024).

## Why it matters for AI safety

Developmental interpretability uses estimated local learning coefficients to track changes in a model during training, so exact coefficients in solvable models are needed for calibration. Reduced-rank regression is a standard singular example with a complete closed form. [MAIS-A6](../agendas/A6/) uses it as a base case for attention and modular-arithmetic calculations; [MAIS-A7](../agendas/A7/) uses its global coefficient as a benchmark while asking for local coefficients across the full matrix-factorization fiber.
